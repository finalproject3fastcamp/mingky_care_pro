# mingky_sensors

I2C ADC(`0x08`)를 **단독으로** 읽어 배터리·초음파·IR을 발행합니다.

```bash
ros2 run mingky_sensors adc_reader
```

운영에서는 `mingky-battery-pub.service`가 상시 실행합니다.

## 왜 단독이어야 하는가

`0x08`은 "커맨드 바이트로 채널 선택 → 2바이트 읽기" 구조이고, **선택된 채널을
하나만 기억합니다.** write와 read 사이에 다른 프로세스가 채널을 바꾸면 엉뚱한
채널 값을 읽습니다.

```
t=0.0ms   A  write 0xF8   배터리 채널 선택
t=0.3ms   B  write 0x88   IR 채널 선택      ← 상태를 덮어씀
t=1.0ms   A  read        → IR 값을 수신     ← 배터리로 인식
```

**I2C 통신은 성공하고 예외도 나지 않습니다.** 반환값은 그냥 숫자라 호출한
쪽에서 오염을 감지할 방법이 없습니다.

실측(2026-08-12, pinky2, 각 40표본):

| 조건 | 중앙값 | 범위 | 이상치 |
|---|---|---|---|
| 리더 1개 | 8.168V | 37mV | 0/40 |
| 리더 2개 | **7.771V** | **3.22V** | 26/40 |
| 되돌린 뒤 | 8.166V | 26mV | 0/40 |

되돌렸을 때 2mV 오차로 복귀했습니다. 오염은 값을 **낮추는 방향으로만**
작용하고, 중앙값 자체가 이동하므로 하류 필터로는 걸러지지 않습니다.

## 측정으로 확인한 것

**지연은 필요 없습니다.** 채널 선택 후 `0us`와 `6000us`의 결과가 같았습니다.
`pinkylib`은 1ms, `pinky_sensor_adc`는 6ms를 넣는데 근거가 없습니다. 그 대기가
곧 임계 구역의 길이라, 없앨수록 충돌 확률이 낮아집니다.

**결합 트랜잭션은 쓸 수 없습니다.** 이 장치는 write와 read 사이에 STOP을
요구합니다. `i2c_rdwr`로 repeated-start를 쓰면 값이 나오지 않습니다(측정 확인).
따라서 원자성은 잠금으로만 얻을 수 있어 `flock`을 겁니다.

**커널 선점이 남습니다.** write 호출이 드물게 3ms까지 걸립니다(p99.9). 언어를
바꿔도 이건 남으므로 잠금이 필요합니다.

## 파라미터

| 이름 | 기본값 | 설명 |
|---|---:|---|
| `battery_period_sec` | `5.0` | 배터리 발행 주기 |
| `battery_samples` | `5` | 한 번 발행할 때 읽는 횟수 (중앙값) |
| `sensor_rate_hz` | `0.0` | 초음파·IR 발행 주기. **0이면 읽지 않음** |
| `settle_sec` | `0.0` | 채널 선택 후 대기 |
| `duplicate_check_sec` | `3.0` | 기동 후 중복 확인까지 대기 |
| `exit_on_duplicate` | `true` | 중복이면 종료 |

`battery_period_sec`를 바꾸지 마세요. `mingky_battery_guard`의 `confirm_window`
와 `trend_samples`가 5초 주기를 전제로 잡혀 있습니다.

## 초음파를 쓰려면

`sensor_rate_hz`를 올리면 `us_sensor/range`와 `ir_sensor/range`가 나옵니다.
기본이 `0.0`인 이유는 아직 구독자가 없고, 검증되지 않은 20Hz 경로를 상시
돌릴 이유가 없어서입니다.

**I2C를 직접 열지 마세요.** `pinkylib.Ultrasonic`을 쓰는 노드를 추가하면 리더가
둘이 되어 배터리까지 같이 망가집니다. 토픽을 구독하면 됩니다.

그리고 쓰기 전에 알아야 할 것이 있습니다.

- **변환식의 근거가 없습니다.** `(adc/4096) - 0.03`이 실제 거리와 어떤 관계인지
  확인된 자료를 찾지 못했습니다. `pinky_study` 위키에도 `get_dist()` 사용
  예제만 있고 측정 범위·정확도·장착 위치가 없습니다.
- **`max_range` 가 어긋나 있습니다.** `pinky_sensor_adc/main_node.cpp`는 `3.0`
  으로 선언하는데, 식이 낼 수 있는 최댓값은 약 `0.97m`입니다. 이 노드는
  `0.97`로 발행합니다.
- **바닥 반사를 확인해야 합니다.** 초음파는 지향각이 넓어(보통 15~30도) 장착
  높이와 각도에 따라 장애물이 없어도 바닥을 감지할 수 있습니다.

## 테스트

```bash
colcon test --base-paths mingky_ros --packages-select mingky_sensors
```

변환식이 `pinkylib`과 어긋나지 않는지 전 구간에서 확인합니다. 부동소수점
결합법칙이 성립하지 않으므로 **연산 순서까지 같게** 유지합니다.
