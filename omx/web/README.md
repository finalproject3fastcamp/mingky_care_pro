# 약국 조제 화면

처방을 받아 OMX 로봇팔이 알약을 순서대로 약통에 담는 화면입니다.
약사가 보는 쪽만 담고 있습니다 — 로봇 상태·엔지니어 화면은 없습니다.

## 바로 실행 (로봇 없이)

**시뮬레이션 모드는 로봇도 카메라도 없이 그대로 돕니다.** UI 를 고칠 때는 이걸로 하십시오.

```bash
cd omx/web
pip install flask
python app.py
```

`http://127.0.0.1:8000` 으로 접속합니다. 조제를 눌러도 로봇은 움직이지 않고
단계만 흘러갑니다.

| 옵션 | 뜻 |
|---|---|
| `--host 0.0.0.0` | 같은 네트워크의 다른 사람도 접속 가능 |
| `--port 8080` | 포트 변경 |
| `--real` | **실제 로봇 연결** — 아래 조건이 필요합니다 |

## 실제 로봇으로 실행

`--real` 은 학습된 정책과 로봇이 있어야 합니다. 조제 담당자 환경에서만 됩니다.

```
필요한 것
  ~/omx_pill_project/         정책 체크포인트와 run.sh
  ~/venv/il                   lerobot v0.4.4
  /dev/omx_follower           로봇팔
  top / wrist 카메라          /dev/v4l/by-id/ 고정 경로
```

없으면 자동으로 시뮬레이션으로 떨어지지 않고 **오류를 표시**합니다 — 로봇이 없는데
있다고 착각하는 것보다 낫기 때문입니다.

## 화면 구성

```
환자 정보    이름·생년월일로 검색 → 고르면 병명과 처방이 자동으로 채워진다
트레이 알약   카메라로 색깔별 개수를 센다 (실제 모드)
처방 선택    병명별 조합. [무작위로 다시 뽑기] 로 조합과 순서를 새로 뽑는다
조제 방식    학습 정책 6종 중 선택 — 발표 중에 바꿔가며 비교할 수 있다
진행 상황    알약별 진행 단계, [조제 시작] [중단] [포장하기] [처음부터]
알림         조제 중 일어난 일 (담기 완료 / 놓쳐서 재시도 / 정지 등)
```

## 데이터 파일

셋 다 JSON 이라 코드를 안 건드리고 고칠 수 있습니다.

| 파일 | 내용 |
|---|---|
| `patients.json` | 시연용 환자 명단. 이름·생년월일·병명·처방코드 |
| `prescriptions.json` | 약품 3종과 병명별 조합 |
| `policies.json` | 조제에 쓸 수 있는 학습 정책 목록 |

환자를 추가하려면 `patients.json` 에 한 줄 넣으면 됩니다. `처방코드` 는
`prescriptions.json` 의 `코드` 와 맞춰야 합니다.

## API

화면을 다시 만들 때 그대로 쓸 수 있습니다.

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| GET | `/api/환자검색?q=` | 이름·생년월일·환자ID·병명으로 검색 |
| GET | `/api/처방목록` | 약품과 병명별 조합 |
| GET | `/api/랜덤처방` | 모든 처방의 색 조합·순서를 새로 뽑는다 |
| GET | `/api/정책목록` | 쓸 수 있는 학습 정책 |
| GET | `/api/트레이` | 트레이의 색깔별 알약 개수 |
| POST | `/api/조제` | 조제 시작 — `{환자, 처방코드, 조합, 정책}` |
| POST | `/api/중단` | 진행 중인 조제 중단 |
| POST | `/api/포장` | 포장 단계 실행 |
| POST | `/api/리셋` | 상태 초기화 (조제 중이면 거절) |
| GET | `/api/상태` | 현재 상태와 단계 |
| GET | `/api/진행` | 진행 상황 스트림 (SSE) |

**조제 요청은 `조합` 을 함께 보내야 합니다.** 처방코드만 보내면 서버의 원본
조합을 쓰므로, 무작위로 뽑은 순서가 무시됩니다.

## 무작위 처방에 걸린 제약

시연에서 "순서를 미리 정해 두지 않았다" 를 보이는 기능인데, 아무 조합이나
뽑으면 로봇이 실패합니다. 두 가지를 지킵니다.

```
① 트레이에 실제로 있는 색에서만 뽑는다
   없는 색을 처방하면 로봇이 찾지 못해 조제가 끝나지 않는다

② 개수는 학습 분포를 따른다
   3개 64.6% / 2개 24.0% / 1개 11.5% / 4개 이상 0%
   4개 이상은 촬영한 적이 없어 정책이 다루지 못한다
```

## 포장 단계

`pack_worker()` 가 4단계(봉투 준비 → 약 투입 → 라벨 인쇄 → 밀봉)를 시간만
흘려보냅니다. **실제 하드웨어가 붙으면 이 함수만 바꾸면 되도록** 분리해
두었습니다. 다른 부분은 손댈 필요가 없습니다.
